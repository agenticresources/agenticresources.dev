# agenticresources.dev
Independent reference for the Agentic Resource Discovery (ARD) specification. Static site on GitHub Pages.

- `index.html` — the site (validator, directory and enquiry form are client-side)
- `.well-known/ard.json` — this site's own ARD manifest (mirrored at `ai-catalog.json`)
- `data/probe-*.json` — raw adoption probe results
